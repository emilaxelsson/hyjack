## Keyboard shortcuts

### Pattern panel

* `Tab` – Switch to sequence panel
* `F2` – Rename pattern

### Sequence panel

* `Tab` – Switch to pattern panel
* `F2` – Rename pattern
* `Up`/`Down` – Move to previous/next pattern
* `Ctrl+D` – Duplicate current entry in the sequence list
* `Delete` – Delete current entry (moves to pool if it is the only reference)
* `Ctrl+Up`/`Ctrl+Down` – Move currrent entry up/down in the sequence list
